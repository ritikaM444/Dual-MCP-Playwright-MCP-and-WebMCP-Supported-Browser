Agent Street

Nine shops. Each has a front door for people, and an AI door for agents.

The front door

Buttons, forms and lists: the way people use any website. An AI agent can come in this way too, by reading the page and clicking and typing like a person. It works on every website, but the agent has to find its way around, which is slower and can go wrong.

In this project: Engine 2, Playwright. Shown in blue.

The AI door

A short menu of actions the shop publishes for agents, like "add to cart" or "book a table". The agent asks for exactly what it wants and gets an exact answer back. Nothing to search for, nothing to misread.

In this project: Engine 1, WebMCP. Shown in green.

Almost no real website has an AI door yet. So the agent checks every page it opens: if there is an AI door, it uses it; if not, it uses the front door. Switching between the two, in the middle of a task, is what this project does.

The shops

Every business here is fictional. Agent Street is the test site for the MCP-Based Autonomous Browser Agent, a final-year project at Vishwakarma University, Pune.
